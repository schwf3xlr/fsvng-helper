# ФСВНГ Helper

Отыгровки, памятки и законы поверх GTA V для УФСВНГ на RMRP. Electron + React + TypeScript.

## Установка

Скачать: [последний релиз](https://github.com/schwf3xlr/fsvng-helper/releases/latest), файл `fsvng-helper-setup-<версия>.exe`. Ставится в Program Files для всех пользователей, ярлык «ФСВНГ Helper» появится на рабочем столе. Подписи у установщика нет, поэтому Windows может показать «Неизвестный издатель»: «Подробнее → Выполнить в любом случае».

Приложение всегда работает с правами администратора: без них Windows не даёт ловить клавиши и показывать окна поверх игры, запущенной от администратора. Права спрашиваются один раз (UAC при первом запуске), дальше программа запускается через задачу планировщика без вопросов. Автозапуск с Windows («Настройки → Запуск и права») тоже сразу с правами.

Версия 0.2.0 ставилась в профиль пользователя — установщик 0.3.0 удалит её сам, настройки сохранятся.

**Перед игрой:** в GTA V «Настройки → Графика → Режим экрана» → **«Оконный без рамки»**. Поверх полноэкранного режима никакие окна не видны — приложение об этом предупредит.

## Два окна

- **Приложение** (F1) — большое обычное окно: отыгровки, памятки, законы, алгоритмы, настройки. Поверх других программ не висит — уходит назад, когда переключаешься в игру или куда-то ещё.
- **Панель в игре** (F3) — компактная колонка поверх GTA, единственное, что всегда поверх: избранные памятки, поиск по законам, алгоритм, список отыгровок, калькулятор. Появляется и прячется без курсора — мышь и фокус остаются у игры. F4 — управлять панелью мышью, Esc — назад в игру. Шаги алгоритма отмечаются клавишами F6 / Shift+F6 без мыши. Панель перетаскивается за заголовок; масштаб (60–160 %), размер и прозрачность — в настройках.

Если клавиши вдруг перестали срабатывать: приложение само следит за перехватом клавиш и ставит его заново, когда Windows его снимает (так бывает под нагрузкой, например при загрузке игры). Вручную — «Перезапустить перехват клавиш» в меню трея. Журнал — «Папка с журналом» там же (`%APPDATA%\fsvng-helper\logs`).

Не ставьте действия на клавиши, которые занимает игра: например, Home в GTA V открывает оверлей Rockstar с курсором. Приложение предупредит о таких клавишах.

## Клавиши по умолчанию

| Клавиша | Действие |
|---|---|
| F1 | Окно приложения |
| F3 | Панель в игре: показать / скрыть |
| F4 | Панель: управлять мышью |
| F6 / Shift+F6 | Отметить шаг алгоритма / снять отметку |
| End | Остановить отыгровку |
| Alt+1…3 | Отыгровки: жетон, осмотр квартиры, права задержанного |

Всё переназначается: «Настройки → Горячие клавиши» и редактор отыгровки. Хоткеи работают, только когда GTA (или само приложение) на переднем плане.

## Что внутри

- **Отыгровки** — список с перетаскиванием, редактор строк с паузами, переменные `{имя}`, `{фамилия}`, `{звание}`, `{подразделение}`, `{жетон}`, `{позывной}`, `{время}`, `{дата}`, `{статьи}` (статьи, отмеченные в калькуляторе), формы по полу `{снял|сняла}`, предпросмотр «как в чате».
- **Памятки** — УК и КоАП собираются из текста закона: наказание и звёзды СПРП по каждой части статьи. ПК, ФЗ о ФСВНГ, об оружии, о закрытых территориях и ФКЗ об особых правовых режимах — краткие пересказы ключевых статей. Избранное, поиск по номеру и слову (с учётом окончаний).
- **Калькулятор наказания** — по каждой статье своя мера: по УК срок или штраф, если он есть в санкции (ч. 2 ст. 13 ПК), по КоАП штраф или арест. Сроки складываются до 15 лет (ч. 2 ст. 30 УК), арест по КоАП при лишении свободы — плюс год (ч. 4 ст. 30 УК). Статьи для личного дела и для протокола о штрафе копируются кнопкой — в окне и в панели.
- **Законы** — полный текст УК, КоАП, ПК, 18-ФЗ, 34-ФЗ, 86-ФЗ и 28-ФКЗ с форума: оглавление, поиск, закладки, последние поправки. Скачиваются с forum.rmrp.ru и обновляются раз в 12 часов, копия хранится на диске.
- **Алгоритмы** — пошаговые чеклисты (задержание и др.): с галочками или просто нумерованным списком. Выбранный алгоритм показывается в панели, шаги отмечаются мышью или клавишей.
- **Настройки** — профили персонажей, клавиши, панель в игре, способ ввода в чат (эмуляция клавиш или вставка), паузы, масштаб, цвет, автозапуск, экспорт и импорт пака для отдела.

При первом запуске мастер спросит профиль и покажет клавиши. Данные: `%APPDATA%\fsvng-helper` (settings.json, законы в `laws/`).

## Разработка

```bash
npm install
npm run dev
```

- `npm run ui` — только интерфейс в браузере на демо-данных (для вёрстки). Законы для демо: папка с `<id>.json` (`uk`, `koap`, `pk`, `fz18`, `fz34`, `fz86`, `fkz28`) в переменной `FSVNG_DEV_LAWS`.
- `FSVNG_USER_DATA=<папка>` — отдельная папка данных для разработки, чтобы не мешать установленной копии (она держит блокировку единственного экземпляра).
- `npm run typecheck` — проверка типов.
- `npm run dist` — установщик в `dist/`.
- `npm run icon` — перерисовать иконку `resources/icon.png`.

## Выпуск новой версии

Установленные копии обновляются сами: проверяют релизы этого репозитория при запуске и раз в 6 часов, скачивают обновление и ставят его при выходе (или по кнопке «Перезапустить» в настройках).

1. Поднять `version` в `package.json`.
2. `npm run dist` — в `dist/` появятся установщик, `.blockmap` и `latest.yml`.
3. Создать релиз `v<версия>` и приложить все три файла:

```bash
gh release create v0.3.1 dist/fsvng-helper-setup-0.3.1.exe dist/fsvng-helper-setup-0.3.1.exe.blockmap dist/latest.yml --title "v0.3.1" --notes "Что изменилось"
```

Без `latest.yml` автообновление новую версию не увидит.
