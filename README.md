# ФСВНГ Helper

Отыгровки, памятки и законы поверх GTA V для УФСВНГ на RMRP. Electron + React + TypeScript.

## Установка

Скачать: [последний релиз](https://github.com/schwf3xlr/fsvng-helper/releases/latest), файл `fsvng-helper-setup-<версия>.exe`. Ставится в профиль пользователя, без прав администратора; ярлык «ФСВНГ Helper» появится на рабочем столе. Подписи у установщика нет, поэтому Windows может показать «Неизвестный издатель»: «Подробнее → Выполнить в любом случае».

**Перед игрой:** в GTA V «Настройки → Графика → Режим экрана» → **«Оконный без рамки»**. Поверх полноэкранного режима никакие окна не видны — приложение об этом предупредит.

## Клавиши по умолчанию

| Клавиша | Действие |
|---|---|
| F1 | Окно приложения (мышь и клавиатура) |
| Ctrl+F1 | Режим «стекло»: окно поверх игры, клики проходят в игру |
| F3 | Памятки поверх игры (стекло на вкладке «Памятки») |
| End | Остановить отыгровку |
| Alt+1…9 | Отыгровки |

Всё переназначается: «Настройки → Горячие клавиши» и редактор отыгровки. Хоткеи работают, только когда GTA (или само окно ФСВНГ Helper) на переднем плане.

## Что внутри

- **Отыгровки** — список с перетаскиванием, редактор строк с паузами, переменные `{имя}`, `{фамилия}`, `{звание}`, `{подразделение}`, `{жетон}`, `{позывной}`, `{время}`, `{дата}`, формы по полу `{снял|сняла}`, предпросмотр «как в чате».
- **Памятки** — УК и КоАП собираются из текста закона: наказание и звёзды СПРП по каждой части статьи. ПК и ФЗ о ФСВНГ — краткие пересказы ключевых статей. Избранное, поиск по номеру и слову, калькулятор наказания, алгоритмы действий с галочками.
- **Законы** — полный текст УК, КоАП, ПК и 18-ФЗ с форума: оглавление, поиск, закладки, последние поправки. Скачиваются с forum.rmrp.ru и обновляются раз в 12 часов, копия хранится на диске.
- **Настройки** — профили персонажей, клавиши, способ ввода в чат (эмуляция клавиш или вставка), паузы, прозрачность стекла, масштаб, акцентный цвет, автозапуск, экспорт и импорт пака для отдела.

Данные: `%APPDATA%\fsvng-helper` (settings.json, законы в `laws/`).

## Разработка

```bash
npm install
npm run dev
```

- `npm run ui` — только интерфейс в браузере на демо-данных (для вёрстки). Законы для демо: папка с `uk.json`, `koap.json`, `pk.json`, `fz18.json` в переменной `FSVNG_DEV_LAWS`.
- `npm run typecheck` — проверка типов.
- `npm run dist` — установщик в `dist/`.
- `npm run icon` — перерисовать иконку `resources/icon.png`.

## Выпуск новой версии

Установленные копии обновляются сами: проверяют релизы этого репозитория при запуске и раз в 6 часов, скачивают обновление и ставят его при выходе (или по кнопке «Перезапустить» в настройках).

1. Поднять `version` в `package.json`.
2. `npm run dist` — в `dist/` появятся установщик, `.blockmap` и `latest.yml`.
3. Создать релиз `v<версия>` и приложить все три файла:

```bash
gh release create v0.2.1 dist/fsvng-helper-setup-0.2.1.exe dist/fsvng-helper-setup-0.2.1.exe.blockmap dist/latest.yml --title "v0.2.1" --notes "Что изменилось"
```

Без `latest.yml` автообновление новую версию не увидит.
